Uber Ride Booking Data Analysis

An analysis of ride bookings that turns raw records into KPIs and patterns about bookings, cancellations and revenue.

3KPIs: successful bookings, cancellation rate, revenue
SQLjoins, aggregations and window functions

Problem

Raw ride-booking records need cleaning and structure before they can show how bookings, customers and rides actually perform.

My role

I cleaned the data, wrote the SQL analysis, and defined the KPIs used to track performance.

Result

A set of KPIs for successful bookings, cancellation rate and revenue, backed by findings on locations, cancellations and revenue trends.

Approach

The analysis worked through these steps:

  • Cleaned missing values, duplicates and inconsistent records.
  • Used joins, aggregations and window functions on booking status, cancellations, revenue and ratings.
  • Found popular pickup and drop locations, cancellation patterns and revenue trends.
  • Defined KPIs to track successful bookings, cancellation rate and revenue.

Tools

  • SQL
  • Excel
  • Power BI
