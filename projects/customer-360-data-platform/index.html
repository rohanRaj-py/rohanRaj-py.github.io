Case study · Data pipeline

Customer 360 Data Platform

Customer data lived in four different kinds of source systems. I built the platform that brings it together into one view of each customer.

4source types: SQL Server, Oracle, APIs, CSV/JSON
3Medallion layers: Bronze, Silver, Gold
Dailyautomated loads with ADF triggers
4data quality checks

Problem

Customer data was spread across SQL Server, Oracle, APIs and CSV/JSON files. Reporting on customer behavior and engagement needs one consistent, cleaned view of each customer.

My role

I built the end-to-end pipeline across all four kinds of source systems, automated its ingestion, added data quality checks, and connected the Gold layer to Power BI.

Result

One customer view, refreshed daily, with Gold tables connected to Power BI for customer behavior and engagement analysis.

Approach

The pipeline follows the Medallion architecture:

BronzeAzure Data Factory loads raw data into ADLS Gen2 on daily triggers
SilverPySpark deduplicates customers, categorizes transactions, segments customers
GoldFact and dimension tables with spend, transactions, visits, session duration

Data quality

Schema validation, null handling, duplicate removal and data type validation.

Tools

  • Azure Data Factory
  • ADLS Gen2
  • Azure Databricks
  • PySpark
  • SQL
  • Power BI
