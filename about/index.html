About

I care about the work that happens before the dashboard.

I'm a B.Tech student in Computer Science & Engineering, specializing in Data Science, based in Noida.

What pulls me in is the part of data work that happens before the dashboard: getting data in, cleaning it and modeling it so the numbers can be trusted.

My projects follow that idea. They pull data from sources like SQL Server, Oracle, APIs and files, clean it in layers on Azure Databricks, and shape it into tables that reporting and SQL analysis can use directly.

I practice problem solving daily and have earned 4 badges for consistency.
